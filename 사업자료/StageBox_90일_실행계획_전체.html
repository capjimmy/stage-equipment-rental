🧭 핵심 실행 원칙 (7가지)

1. 공급 우선 (Supply First)

수요 없이 공급 확보가 먼저. 상품이 없으면 고객이 와도 살 게 없다.

  • 처음 4주는 영업/섭외에 80% 집중
  • 개발은 공급자 편의 기능 위주
  • "볼거리 있는 플랫폼" 만들기

2. 신뢰가 곧 경쟁력

렌탈 비즈니스는 신뢰가 핵심. 첫 거래, 첫 정산을 완벽하게.

  • 약속한 정산일에 정확히 입금
  • 문제 발생 시 빠른 대응
  • 투명한 정보 공개

3. 직접 경험으로 배우기

초기엔 모든 과정을 직접 경험. 자동화는 패턴 파악 후.

  • 첫 10건은 수동으로 처리
  • 반복 패턴 발견 후 자동화
  • 예외 케이스 정책화

4. 작은 성공 빠르게

완벽한 시스템보다 빠른 첫 성공이 중요.

  • MVP로 빠르게 검증
  • 1건의 성공 사례 = 10개 영업 무기
  • 완벽주의 경계

5. 현장에서 답을 찾기

책상에서 추측하지 말고 현장에서 듣기.

  • 주 2회 이상 현장 방문
  • 공급자/수요자 피드백 수집
  • 실제 사용 패턴 관찰

6. 통제보다 편의 제공

직거래 방지에 집착하지 말고 "플랫폼이 더 편하다"를 증명.

  • 복잡한 규제 대신 좋은 UX
  • 부가가치로 Lock-in
  • 자연스러운 거래 유도

7. 문제 = 기회

클레임, 분쟁은 정책 수립과 개선의 기회.

  • 모든 문제 케이스 기록
  • 패턴 발견 → 정책화
  • FAQ/가이드 업데이트

❓ 공급자 FAQ (핵심 5개)

Q1. 수수료가 50%면 너무 높은 거 아닌가요?
저희가 마케팅, 고객 확보, 결제, CS를 모두 담당합니다. 기존 고객은 그대로 유지하시고, 저희를 통해 추가 고객만 받으시면 50%가 순수익입니다.
Q2. 정산은 언제, 어떻게 되나요?
매월 1~말일 거래분을 익월 15일에 정산합니다. 정산서는 10일에 미리 보내드리고, 확인 후 입금 + 세금계산서 발행합니다.
Q3. 물건이 파손되면 누가 책임지나요?
수요자(빌린 사람) 책임입니다. 고가 품목은 보증금을 미리 받고, 파손 시 차감 후 정산합니다.
Q4. 예약이 겹치면 어떻게 하나요?
저희 시스템이 자동으로 재고/기간 체크합니다. 더블부킹 걱정 없습니다.
Q5. 언제든 그만둘 수 있나요?
네, 계약 해지는 30일 전 통보로 가능합니다. 위약금 없습니다.
