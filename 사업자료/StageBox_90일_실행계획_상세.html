🧭 핵심 실행 원칙 (7가지)

1. 공급 우선 (Supply First)

수요 없이 공급 확보가 먼저. 상품이 없으면 고객이 와도 살 게 없다.

  • 처음 4주는 영업/섭외에 80% 집중
  • 개발은 공급자 편의 기능 위주
  • "볼거리 있는 플랫폼" 만들기

2. 신뢰가 곧 경쟁력

렌탈 비즈니스는 신뢰가 핵심. 첫 거래, 첫 정산을 완벽하게.

  • 약속한 정산일에 정확히 입금
  • 문제 발생 시 빠른 대응
  • 투명한 정보 공개

3. 직접 경험으로 배우기

초기엔 모든 과정을 직접 경험. 자동화는 패턴 파악 후.

  • 첫 10건은 수동으로 처리
  • 반복 패턴 발견 후 자동화
  • 예외 케이스 정책화

4. 작은 성공 빠르게

완벽한 시스템보다 빠른 첫 성공이 중요.

  • MVP로 빠르게 검증
  • 1건의 성공 사례 = 10개 영업 무기
  • 완벽주의 경계

5. 현장에서 답을 찾기

책상에서 추측하지 말고 현장에서 듣기.

  • 주 2회 이상 현장 방문
  • 공급자/수요자 피드백 수집
  • 실제 사용 패턴 관찰

6. 통제보다 편의 제공

직거래 방지에 집착하지 말고 "플랫폼이 더 편하다"를 증명.

  • 복잡한 규제 대신 좋은 UX
  • 부가가치로 Lock-in
  • 자연스러운 거래 유도

7. 문제 = 기회

클레임, 분쟁은 정책 수립과 개선의 기회.

  • 모든 문제 케이스 기록
  • 패턴 발견 → 정책화
  • FAQ/가이드 업데이트
