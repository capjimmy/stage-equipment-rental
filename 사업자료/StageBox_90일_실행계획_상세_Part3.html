필드명 타입 필수 설명 예시/제약조건
🔹 기본 정보
id string 필수 상품 고유 ID (자동 생성) prod_abc123xyz (21자)
supplierId string 필수 공급자 ID (외래키) sup_xyz789
name string 필수 상품명 최대 100자, "빅토리아 시대 볼가운 (빨강)"
description string 필수 상세 설명 최대 2000자, 마크다운 지원
shortDescription string 선택 짧은 설명 (목록용) 최대 150자
categoryId string 필수 카테고리 ID (최하위) "costumes/historical/victorian"
tags string[] 선택 검색용 태그 최대 10개, ["빅토리아", "드레스", "빨강"]
sku string 선택 공급자 자체 상품 코드 "VIC-DR-001"

🔒 재고 충돌 방지 규칙

# 규칙 설명 구현 방식 예외 처리
1 수량 체크 예약 요청 시 해당 기간에 가용 수량 확인 availableQty = totalQty - reservedQty(period)
availableQty >= requestQty 		가용 수량 부족 시 예약 거절
2 버퍼 기간 예약 간 정비/세탁을 위한 버퍼 예약 종료일 + bufferDays 이후부터 다음 예약 가능
예: bufferDays=1이면 2/10 반납 → 2/12부터 가능 		버퍼 기간 내 예약 불가
3 동시 요청 처리 같은 시간에 동일 상품 요청 Firestore Transaction 사용
먼저 commit된 요청만 성공 		"이미 예약됨" 안내, 대안 추천
4 결제 잠금 결제 진행 중 임시 잠금 결제 시작 시 15분간 임시 예약 (PENDING)
결제 미완료 시 자동 해제 		타임아웃 시 EXPIRED로 전환
5 최소 사전 예약 너무 급한 예약 방지 오늘로부터 advanceBookingDays 이후만 예약 가능
예: 3일 설정 시 D+3부터 		빠른 날짜 선택 시 안내
6 연체 처리 반납 지연 시 다음 예약 보호 반납일 D+1 자동 OVERDUE 전환
D+3까지 미반납 시 다음 예약자 공지 		긴급 대체품 연결, 환불 처리

// 특정 기간의 가용 수량 계산 async function getAvailableQuantity( productId: string, startDate: Date, endDate: Date ): Promise<number> { // 1. 상품 정보 조회 const product = await getProduct(productId); const totalQty = product.quantity; const bufferDays = product.bufferDays || 0; // 2. 해당 기간과 겹치는 예약 조회 // (버퍼 기간 포함하여 조회) const overlappingReservations = await db.collection('reservations') .where('productId', '==', productId) .where('status', 'in', ['PENDING', 'CONFIRMED', 'SHIPPED', 'IN_USE']) .get(); // 3. 요청 기간과 겹치는 예약만 필터 const conflicting = overlappingReservations.docs.filter(doc => { const rsv = doc.data(); const rsvStart = rsv.startDate.toDate(); const rsvEnd = addDays(rsv.endDate.toDate(), bufferDays); // 기간 겹침 체크 return !(endDate < rsvStart || startDate > rsvEnd); }); // 4. 각 날짜별 예약 수량 계산 const reservedByDate: Record<string, number> = {}; for (const doc of conflicting) { const rsv = doc.data(); const effectiveStart = rsv.startDate.toDate(); const effectiveEnd = addDays(rsv.endDate.toDate(), bufferDays); let current = effectiveStart; while (current <= effectiveEnd) { const key = formatDate(current); reservedByDate[key] = (reservedByDate[key] || 0) + rsv.quantity; current = addDays(current, 1); } } // 5. 요청 기간 중 최대 예약 수량 let maxReserved = 0; let current = startDate; while (current <= endDate) { const key = formatDate(current); maxReserved = Math.max(maxReserved, reservedByDate[key] || 0); current = addDays(current, 1); } return totalQty - maxReserved; } // 예약 가능 여부 확인 async function canReserve( productId: string, startDate: Date, endDate: Date, requestQty: number ): Promise<boolean> { const available = await getAvailableQuantity(productId, startDate, endDate); return available >= requestQty; } // 예약 생성 (Transaction으로 동시성 처리) async function createReservation(data: ReservationInput): Promise<Reservation> { return db.runTransaction(async (transaction) => { // 1. 다시 한번 가용성 체크 (Transaction 내에서) const available = await getAvailableQuantity( data.productId, data.startDate, data.endDate ); if (available < data.quantity) { throw new Error('INSUFFICIENT_STOCK'); } // 2. 예약 생성 const reservationRef = db.collection('reservations').doc(); const reservation = { id: reservationRef.id, ...data, status: 'PENDING', createdAt: new Date(), expiresAt: addMinutes(new Date(), 15), // 15분 후 만료 }; transaction.set(reservationRef, reservation); return reservation; }); }
